С другим [[ОТРЯДЫ]]
1. Когда [[ОТРЯДЫ]] создают [[✦СВЯЗЬ]] между собой, они вместо этого создают [[СВЯЗЬ ОТРЯДА]] с другим [[ОТРЯДЫ]], которая действует аналогично обычной, но действует между [[ОТРЯДЫ]], как если бы эти два [[ОТРЯДЫ]] были двумя обычными существами

С не [[ОТРЯДЫ]]
1. Если же  [[✦СВЯЗЬ]] создает [[ОТРЯДЫ]] с не [[ОТРЯДЫ]] или не [[ОТРЯДЫ]] создает [[✦СВЯЗЬ]] с [[ОТРЯДЫ]], то вместо этого [[ОТРЯДЫ]] создает [[СПУТНИКИ]] из которых состоит в количестве d6. Они имеют [[✦СВЯЗЬ]] друг с другом а также, каждый из них будет иметь [[✦СВЯЗЬ]] с не [[ОТРЯДЫ]].
2. При этом, если количество [[СПУТНИКИ]] созданных таким образом равно 1, то [[ОТРЯДЫ]] также получает свойство [[⭗ПОТЕРЯ МОРАЛИ]].

Если уже существует [[СВЯЗЬ ОТРЯДА]], вместо создания новой [[СВЯЗЬ ОТРЯДА]] инициатор связаывается с одним уже существующим [[СПУТНИКИ]]  этого [[ОТРЯДЫ]]. Т.е. нельзя создать [[СВЯЗЬ ОТРЯДА]] , пока на поле есть [[СПУТНИКИ]] этого [[ОТРЯДЫ]].
